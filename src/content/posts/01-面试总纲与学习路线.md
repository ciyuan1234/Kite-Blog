# 卷九 · 面试准备（面向应届生）

## 第 01 章 面试总纲


### 01.1 agent 岗位全景：面试官到底考什么

"agent 相关岗位"可以拆成三类，JD 里通常能对号入座：

**A 类：LLM/Agent 应用开发**（最常见的应届岗）
- 职责：用现成框架（LangChain、Dify、自研框架）做 agent 产品：RAG、工作流编排、工具调用、客服/编程助手等。
- 考察点：LLM 基础（token、上下文、function calling）、提示词工程、RAG 链路、Agent 循环原理、动手能力（demo）。
- 简历匹配度：★★★（dsh 的循环机制、工具调用、上下文管理都能讲）

**B 类：Agent 框架/平台开发**（进阶岗，也可能校招有）
- 职责：做 agent 框架本身：会话管理、工具系统、插件体系、多智能体、权限安全、平台化。
- 考察点：系统设计、并发、架构取舍、可扩展性设计、对 agent 系统痛点的理解。
- 简历匹配度：★★★★★（dsh 就是这类系统的完整范本，你有别人没有的深度）

**C 类：AI 后端/推理工程**（更偏服务端）
- 职责：模型接入、推理服务、Prompt 服务、缓存、评估。
- 考察点：网络编程、并发、流式协议、稳定性工程。
- 简历匹配度：★★（dsh 的 SSE 解析、超时、重试、适配器能讲）

**面试官共通的底层考察矩阵**（无论哪类）：

| 维度     | 具体表现                                                                        |
| -------- | ------------------------------------------------------------------------------- |
| 行业认知 | 知道 LLM 怎么工作、agent 为什么是热点、常见坑（幻觉、上下文溢出、工具调用失败） |
| 项目深度 | 项目是"背过"还是"真懂"：深挖 2-3 层还能答                                       |
| 工程能力 | 并发、异步、错误处理、测试、可维护性                                            |
| 学习能力 | 新技术怎么学、踩坑怎么解决                                                      |
| 沟通表达 | 30 秒讲清项目、术语准确、逻辑分层                                               |

你的策略：**用 dsh 一个项目同时打中 A、B、C 三类**——A 类讲"agent 循环怎么转"，B 类讲"框架怎么设计"，C 类讲"模型接入与稳定性"。本文案前八卷给了你事实，本卷给你讲述方式。

### 01.2 总学习路线（12 周）

总原则：**先懂后写，先讲后答**。每周 10-15 小时（课业之外），分四个阶段。

**第一阶段：地基——TS 与行业常识**
- 第 1 周：读 `21-TypeScript快速入门.md`，对照你的 Python/Java 基础速成 TS；每天在 playground 写 30 分钟；完成"手写代码准备"第 10 章的基础题（LRU、事件发射器、并发池）。
- 第 2 周：读 `22-LLM与Agent行业知识.md`；用一个 API key（DeepSeek 或任何便宜模型）亲手调一次 streaming 接口、一次 function calling，把返回的 JSON 打印出来看。产出：一个"调模型的最小脚本"。
- 里程碑：能不看资料写出带类型标注的 TS 异步代码；能解释 token、上下文窗口、temperature、function calling 是什么。

**第二阶段：啃项目——从总览到核心**
- 第 3 周：通读卷一并选读附录；然后精读 `05-系统提示词与工具.md` 与 `06-Agent与循环引擎.md`，对照源码 `packages/core/agent-loop/src/agent.ts` 走一遍 turn/step 流程，手动画一张流程图画在笔记里。
- 第 4 周：精读 `04-作用域与品牌类型.md`、`07-持久化投影与检索.md`；理解"事件溯源 + 投影"为什么是 agent 系统的地基；读 `23-核心概念通俗版.md`，尝试自己把每个概念讲给同学听（讲不出来=没懂）。
- 第 5 周：选两个能力缝深读：shell（`09-执行与网络能力.md`）与 subagent（`10-技能子代理与杂项工具.md`）；跑通 `examples/headless-agent`，给 headless 加一个小工具插件，让 agent 调用它。产出：**你给 dsh 写的第一个插件**（完整步骤与代码见 `31-动手实战教程.md` 项目 A）。
- 第 6 周：读卷四（LLM）、卷六（通信）、卷七（治理）的精华章节；整理出"10 个亮点"清单（直接抄 `24-项目亮点与面试话术.md` 然后改成自己的话）；启动 `31-动手实战教程.md` 项目 B（mini agent）的 M0-M1。
- 里程碑：能不看文档、用大白话讲"这个项目是什么"，能讲出循环流程与事件溯源。

**第三阶段：转化成面试资产**
- 第 7 周：用 `24-项目亮点与面试话术.md` 写自己的 30 秒 / 3 分钟 / 15 分钟三个版本项目介绍，录视频回放，改到自然。
- 第 8 周：逐题过 `25-高频面试题解析.md`（40 题），每题先自己答、再看解析；不会的先查卷一到卷八对应章节。
- 第 9 周：`26-系统设计题演练.md` 三道题各写一版"设计讲稿"（不用真写代码，用画图+口述）；`27-简历项目描述.md` 改简历。
- 里程碑：高频题 40 题全部能答出框架；项目介绍能脱稿 3 分钟。

**第四阶段：深挖与实战**
- 第 10 周：`28-面试官深挖题与应对.md` 逐题过；找同学/学长做两次模拟面试（用 `30-模拟面试与自测清单.md` 的脚本）。
- 第 11 周：`29-手写代码准备.md` 的 agent 场景题全部上机写一遍（ReAct 循环、工具注册表、SSE 解析、token 截断）；整理"踩坑笔记"（面试聊踩坑非常加分）；完成 `31-动手实战教程.md` 项目 B 的 M2-M4 与项目 C。
- 第 12 周：整体复盘：重读一遍 README 与导读，把简历、项目介绍、自测清单过一遍；如投 DeepSeek 先过 `32-DeepSeek专项准备.md`；算法轮进度对照 `33-算法轮与基础轮清单.md`；开始投递。
- 里程碑：模拟面试两次 45 分钟无卡顿；手撕题 15 分钟以内完成。

### 01.3 每阶段的产出物（简历与面试的素材库）

- 第 2 周产出：最小 LLM 调用脚本 → 面试可讲"我自己调过 streaming 和 function calling"。
- 第 5 周产出：dsh 自定义插件 → 面试可讲"我读懂了框架的扩展点，给项目加过插件"。
- 第 7 周产出：三个版本的项目介绍视频 → 面试的开场就靠它。
- 全程产出：笔记（每章读完写 200 字小结）→ 面试被深挖时有据可依。

### 01.4 本卷使用方式

- 学习期：按路线图顺序读，配合源码与 API。
- 求职期：只复习 `24`（话术）、`25`（高频题）、`30`（自测清单）。
- 面试当天：只看 `30-模拟面试与自测清单.md` 的"最终检查清单"。

### 01.5 心态与红线

1. **诚实是第一原则**：简历写了"深入理解"就要能扛住深挖；不会就说"这个我还没深入，我理解的是……"。面试官讨厌的不是不会，是装会。
2. **大三应届生的合理定位**：面试官不期待你有工作经验，期待的是"有真实项目学习能力 + 基础扎实 + 表达清楚"。dsh 这种高质量开源项目是你的差异化优势——多数应届生只有课程项目。
3. **别背稿**：背出来的回答一听就假。本卷给的模板是"骨架"，你要用自己的话填肉。
4. **代码量为王**：2-3 个月里至少产出 3 个代码产物（调模型脚本、dsh 插件、手撕题集），简历上"写了什么"永远比"看过什么"有力。
