# 回调函数（Callback）学习笔记

> 本笔记整理自本次关于“回调函数”的讨论。
>
> **当前范围：只整理回调函数及其相关概念。**
> 函数指针、指针函数等容易混淆的内容暂不展开，后续单独讨论。

---

## 1. 什么是回调函数？

### 核心定义

**回调函数（Callback Function）**：

> 把一个函数/可调用对象作为参数交给另一个函数或组件，由后者在合适的时间调用它。

核心不是某一种语法，而是一种**编程思想和调用机制**。

可以理解成：

```text
调用者
  │
  │ 把“以后要执行的行为”交给另一个函数
  ▼
被调用函数
  │
  │ 在合适的时候调用
  ▼
回调
```

### 一句话记忆

> **回调 = 把“以后做什么”交给别人决定。**

---

## 2. 回调解决什么问题？

普通写法可能把调用关系写死：

```cpp
void process() {
    login();
    save();
    send_email();
}
```

此时 `process()` 明确依赖 `login()`、`save()` 和 `send_email()`。

如果以后想改成短信：

```cpp
send_sms();
```

就需要修改 `process()`。

这会产生较强的耦合。

---

## 3. 使用回调实现解耦

可以把“处理完成后做什么”交给外部：

```cpp
void process(std::function<void()> callback) {
    // 做自己的事情

    callback();
}
```

调用时决定具体行为：

```cpp
process(send_email);
```

或者：

```cpp
process(send_sms);
```

此时：

```text
              ┌── send_email
              │
process ─ callback
              │
              └── send_sms
```

`process()` 不需要知道具体调用的是谁。

它只需要知道：

> “你给我的东西符合要求，并且我可以在需要的时候调用它。”
