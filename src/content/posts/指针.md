# C/C++ 函数指针、指针函数与回调函数

## 1. 核心结论

> **函数指针 ≈ 保存函数地址的指针**
>
> **回调函数 ≈ 把函数作为参数传给另一个函数**
>
> **指针/引用参数 ≈ 让函数能够操作调用者提供的对象**

这三个概念经常一起出现，但它们不是同一个概念。

---

## 2. 函数也有地址吗？

有。

例如：

```cpp
int add(int a, int b)
{
    return a + b;
}
```

程序运行时，`add` 对应的机器指令会位于进程的代码区域中。

可以粗略理解为：

```text
内存

0x1000 ──→ add() 的机器指令
0x2000 ──→ main() 的机器指令
0x3000 ──→ 其他函数的机器指令
```

因此，函数有一个可以用于定位其代码的地址。

---

## 3. 函数指针是什么？

普通变量：

```cpp
int x = 10;
int* p = &x;
```

可以理解为：

```text
p
│
│ 保存 x 的地址
↓
x = 10
```

函数指针也是类似的思想：

```cpp
int add(int a, int b)
{
    return a + b;
}

int (*p)(int, int) = &add;
```

可以理解为：

```text
p
│
│ 保存 add 的地址
↓
add()
```

所以：

```cpp
int (*p)(int, int);
```

表示：

> `p` 是一个指针，它指向一个“接收两个 `int`、返回 `int`”的函数。

调用：

```cpp
p(10, 20);
```

就相当于调用：

```cpp
add(10, 20);
```

---

## 4. 为什么函数指针写成 `(*p)`？

比较：

```cpp
int* func();
```

和：

```cpp
int (*p)();
```

### `int* func()`

`func()` 优先结合，因此：

```text
func
 ↓
函数
 ↓
返回 int*
```

这是**指针函数**。

### `int (*p)()`

因为 `(*p)` 被括起来：

```text
p
 ↓
指针
 ↓
指向函数
 ↓
函数返回 int
```

这是**函数指针**。

因此括号非常重要。

---

## 5. 函数指针 vs 指针函数

| 类型 | 示例 | 本质 | 含义 |
|---|---|---|---|
| 函数指针 | `int (*p)(int, int)` | 指针 | 指向函数 |
| 指针函数 | `int* func(int, int)` | 函数 | 返回指针 |

### 记忆方法

看到：

```cpp
int (*p)(int, int);
```

先看：

```cpp
(*p)
```

说明：

> `p` 是指针。

然后发现它指向函数。

所以：

> **函数指针**

---

看到：

```cpp
int* func(int, int);
```

先看：

```cpp
func(...)
```

说明：

> `func` 是函数。

然后发现它返回 `int*`。

所以：

> **指针函数**

---

## 6. 函数指针和普通指针的相似之处

它们都可以理解为：

> **一个指针保存某个目标的地址。**

普通指针：

```text
指针 ─────→ 数据
```

函数指针：

```text
函数指针 ─→ 函数代码
```

例如：

```cpp
int x = 10;
int* p = &x;
```

以及：

```cpp
int add(int a, int b)
{
    return a + b;
}

int (*p)(int, int) = &add;
```

两者在“保存地址”这个层面非常相似。

但是二者指向的对象不同：

- 普通指针通常指向数据对象
- 函数指针指向函数

---

## 7. 为什么 `p = add` 通常也可以？

下面两种写法通常都可以：

```cpp
int (*p)(int, int) = add;
```

```cpp
int (*p)(int, int) = &add;
```

在这种上下文中，函数名 `add` 会转换成指向该函数的指针。

所以可以把：

```cpp
p = add;
```

粗略理解为：

```cpp
p = &add;
```

---

## 8. 回调函数是什么？

回调函数的核心不是“修改变量”，而是：

> **把一个函数传给另一个函数，让另一个函数在适当的时候调用它。**

例如：

```cpp
void hello()
{
    std::cout << "Hello\n";
}

void execute(void (*callback)())
{
    callback();
}
```

调用：

```cpp
execute(hello);
```

过程：

```text
hello
 ↓
函数地址
 ↓
callback
 ↓
execute() 调用 callback()
```

这就是回调。

---

## 9. 回调函数和地址传递是两个不同的问题

这是学习过程中非常容易混淆的地方。

### 回调解决什么？

回调解决：

> **“调用哪个函数？”**

例如：

```cpp
void execute(void (*func)());
```

这里的 `func` 是函数指针。

---

### 指针/引用参数解决什么？

参数传递解决：

> **“函数能不能修改调用者提供的对象？”**

例如：

```cpp
void callback(int x)
{
    x = 100;
}
```

调用：

```cpp
int a = 10;
callback(a);
```

结果：

```text
a == 10
```

因为 `x` 是 `a` 的一份副本。

---

## 10. 如果希望函数修改外部变量

可以使用指针：

```cpp
void callback(int* x)
{
    *x = 100;
}

int a = 10;
callback(&a);
```

执行后：

```text
a == 100
```

过程：

```text
a
│
│ &a
↓
x
```

因此：

```cpp
*x = 100;
```

实际上修改的是 `a`。

---

## 11. C++ 中通常可以使用引用

C 风格：

```cpp
void callback(int* x)
{
    *x = 100;
}

int a = 10;
callback(&a);
```

C++ 可以写成：

```cpp
void callback(int& x)
{
    x = 100;
}

int a = 10;
callback(a);
```

这样更直观。

这里 `x` 是 `a` 的引用，因此：

```cpp
x = 100;
```

实际上修改的是：

```cpp
a
```

---

## 12. 回调 + 引用/指针可以组合

例如：

```cpp
void callback(int& x)
{
    x += 10;
}

void execute(void (*func)(int&), int& value)
{
    func(value);
}

int main()
{
    int a = 20;

    execute(callback, a);

    std::cout << a << std::endl;
}
```

执行过程：

```text
a = 20
 │
 │ 传给 execute
 ↓
value
 │
 │ 调用 func
 ↓
callback(int& x)
 │
 │ x += 10
 ↓
a = 30
```

这里同时出现了两个不同的机制。

### 第一层：传函数

```cpp
execute(callback, a);
```

`callback` 被作为参数传给 `execute`。

这是：

> **函数指针 / 回调**

### 第二层：传变量

```cpp
func(value);
```

这里使用引用，使 `callback` 能够修改原来的 `a`。

这是：

> **引用传递**

---

## 13. 三个概念必须分开

```text
                    函数调用
                       │
             ┌─────────┴─────────┐
             ↓                   ↓
          普通调用              回调
             │                   │
       直接调用函数          把函数传进去
                                 │
                                 ↓
                            函数指针
                                 │
                                 ↓
                         保存函数的地址
```

而参数传递是另外一个维度：

```text
参数传递
   │
   ├── 值传递
   │      ↓
   │    复制一份
   │
   ├── 指针传递
   │      ↓
   │    传地址
   │
   └── 引用传递
          ↓
        操作原对象
```

因此：

> **回调 ≠ 地址传递**

> **函数指针 ≠ 变量指针**

> **是否能够修改外部变量，取决于参数传递方式，而不是取决于是不是回调。**

---

## 14. 一张总表

| 概念 | 解决的问题 | 典型写法 |
|---|---|---|
| 普通指针 | 保存数据对象的地址 | `int* p` |
| 函数指针 | 保存函数的地址 | `int (*p)(int)` |
| 指针函数 | 函数返回一个指针 | `int* func()` |
| 回调函数 | 把函数传给另一个函数 | `execute(callback)` |
| 值传递 | 给函数一份数据副本 | `func(int x)` |
| 指针传递 | 让函数通过地址访问对象 | `func(int* x)` |
| 引用传递 | 让函数直接操作原对象 | `func(int& x)` |

---

## 15. 最终记忆

只记住下面四句话：

> **函数指针：指针指向函数。**

> **指针函数：函数返回指针。**

> **回调函数：把函数传进去，让另一个函数调用它。**

> **指针/引用参数：决定函数是否能够通过参数修改外部对象。**

最重要的是不要把最后两个概念混在一起：

```text
函数指针 / 回调
        ↓
“调用谁？”

指针 / 引用参数
        ↓
“能不能修改谁？”
```

这两个问题经常组合使用，但本质上是**两个独立的概念**。
